# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue. Use
GitHub's [private vulnerability reporting](https://github.com/jmozez/tidydiversity/security/advisories/new)
or email the maintainer, Jimmy Moses, at <jimmy.moses@pnguot.ac.pg>.

Include the tidydiversity version, R version, and a minimal example that
shows the problem. You should receive a reply within two weeks.

## Supported versions

Only the latest development version on the `main` branch receives fixes.
